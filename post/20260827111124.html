版本：Claude‑Code 2.1.247 说明：Claude‑Code 是终端CLI工具，不是桌面软件；国内无法直接使用Anthropic官方账号，依靠国产大模型兼容Anthropic协议API实现使用。 ⚠️官方一键脚本 irm claude.ai/install.ps1 | iex 国内网络会被Cloudflare拦截，直接废弃不要使用。

一、前置环境

1. 软件依赖

  • Windows10 / Windows11
  • Node.js ≥18 LTS（推荐安装24版本），安装时务必勾选 Add to PATH
  • Git（可选，用于识别git项目，不安装也能运行）

2. 验证环境

打开 Windows PowerShell（不要用CMD命令提示符）

正常输出版本号代表环境就绪。

3. API准备（二选一）

  1. DeepSeek：DeepSeek 开放平台获取API Key，按量计费
  2. 智谱AI：智谱丨BigModel 平台获取API Key

全程不需要科学上网，模型请求全部走国内接口；仅客户端会尝试访问海外地址做遥测上报，该请求失败属于正常警告，不影响功能。

⚠️重要避坑

  1. 第三方兼容API必须使用 ANTHROPIC_AUTH_TOKEN，禁止写ANTHROPIC_API_KEY，写错直接报Not logged in
  2. base_url不要手动追加/v1后缀，会404；直接复制平台给出的Anthropic兼容接口地址
  3. JSON语法校验：复制内容到 json.cn，无报错才合格。

四、启动运行

  1. 重新打开PowerShell，切换到你的项目目录，不要在C:\Windows\System32运行claude
  1. 首次运行询问信任目录：输入 y 回车授权访问本地文件。

出现红色警告：无法连接api.anthropic.com，为客户端遥测上报，直接忽略，不影响对话、读写文件。

五、DeepSeek计费简单说明

2026‑08，按token按量计费，输入输出分开计费；支持上下文缓存优惠；V4系列有峰谷定价。

  • 高峰（工作日9‑12点、14‑18点）价格翻倍；周末全天为低价空闲时段
  • deepseek‑v4‑flash：性价比最高，适合日常写代码
  • deepseek‑reasoner(R1)：推理模型，输出token很贵，不建议日常编码使用
  • 平台控制台开启用量告警，防止无意识消耗大量token。

六、高频报错排错清单

报错现象 解决方案
Not logged in · Run /login 1.确认变量名ANTHROPIC_AUTH_TOKEN；2.检查.claude.json；3.密钥无多余空格；4.完全重启终端
404 Not Found base_url不要手动加/v1后缀，严格复制官方Anthropic兼容地址
能聊天，但是不能读写文件、执行shell 接口不完整支持tool_use工具调用；DeepSeek使用v4‑flash；智谱需要开通Coding编码套餐
claude不是内部命令 全部关闭终端，重新打开；确认npm全局安装成功
JSON解析报错 检查json逗号、引号，不能有中文全角符号，不要出现两组独立大括号
PowerShell识别不了New‑Item / Out‑File命令 不要使用CMD，打开真正Windows PowerShell；或者手动创建配置文件

⚠️版本更新风险：升级Claude‑Code新版本后，.claude.json的hasCompletedOnboarding:true有可能被重置，会重新弹出登录引导，需要重新检查该文件。

八、重要注意事项

  1. 本方案属于社区魔改用法，非Anthropic官方支持，客户端更新后存在兼容波动可能性。
  2. 所有配置修改完成，必须关闭全部终端窗口，新开终端才会加载新配置。
  3. 不要把settings.json放到错误目录，路径错误会直接读取不到配置。
  4. 不要在系统目录C:\Windows\System32运行claude，必须切换到业务项目目录。
